# План команды после Final 1.0

Final 1.0 закрывает основной учебный сценарий. Следующий цикл нужен не для переписывания продукта, а для проверки на компьютерах команды, подготовки доступного стенда, улучшения дизайна и оформления доказательств для сдачи.

## Текущее состояние

Готово: личное и проектное хранилище, версии, избранное, корзина, роли, кастомизация проекта, чек‑лист, итоговый файл, ZIP, две модели публичных ссылок, аудит, 2FA, прикладное шифрование, администрирование, локальная сборка и документация.

Требует внешней проверки: настоящий Chromium/Windows, Docker PostgreSQL + MinIO, публичный HTTPS, production-секреты, восстановление контейнерного стенда и пользовательские отзывы.

## Пользовательские проверки

Минимум три сценария:

1. Новый пользователь без подсказки создаёт проект, приглашает участника и загружает файл.
2. Участник добавляет версию и отмечает задачу выполненной.
3. Владелец выбирает final и отправляет преподавательскую ссылку.

Фиксировать: время, ошибки, вопросы, непонятные слова и место остановки. Не подсказывать до завершения попытки. Замечание считается закрытым только после повторной проверки.
